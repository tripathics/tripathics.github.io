<h2 id="goals">Goals<a href="#goals" aria-hidden="true" tabindex="-1" class="heading-link"><svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 24 24" width="1em" height="1em" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="M10 13a5 5 0 0 0 7.54.54l3-3a5 5 0 0 0-7.07-7.07l-1.72 1.71"></path><path d="M14 11a5 5 0 0 0-7.54-.54l-3 3a5 5 0 0 0 7.07 7.07l1.71-1.71"></path></svg></a></h2>
<ol>
<li>We will create an <code>&#x3C;Alert /></code> component with following features:
<ul>
<li>Different levels of severity like info, success, warning and error.</li>
<li>Dismiss action button.</li>
<li>Auto-dismiss according to severity level or according to <code>timeout</code> time.</li>
</ul>
</li>
<li>We will create a wrapper for all alerts, <code>&#x3C;AlertsWrapper /></code>. All the alerts within the app will stay inside this wrapper</li>
<li>We will create an <code>AlertContext</code>:
<ul>
<li><code>State</code> to store alerts, i.e. support for multiple alerts.</li>
<li><code>addAlert()</code> function to add new alerts.</li>
<li><code>removeAlert()</code> function to clear all alerts.</li>
</ul>
</li>
<li><code>useAlerts</code> hook to access the alert system.</li>
</ol>

<p>The alerts are not getting cleared. This is because when the <code>&#x3C;AlertTestForm /></code> the states also get lost. Thus there is nothing to "clear" and the alerts are not getting cleared. We can use the <a href="https://react.dev/reference/react/useRef"><code>useRef</code></a> hook to keep track of the alert ids that are added by this component.</p>
<p>The system of alerts we're making is supposed to be used by many pages in the app. Instead of declaring these state variables for <code>alertIds</code>, references for not losing these <code>alertIds</code>, functions to <code>clearAlerts()</code> and handling clearing of alerts in the component's cleanup function, we can create a custom hook.</p>

<p>We have made an Alert system where:</p>
<ul>
<li>One can easily trigger alerts by using the <code>useAlerts</code> hook's <code>addAlert()</code> function from any component below the <code>&#x3C;AlertsProvider /></code>.</li>
<li>The system supports showing multiple alerts at a time with features like auto-dismiss with timer.</li>
<li><code>clearAlerts()</code> function can be used clear alerts created by a component. It which can be used to clear alerts as a component (like a page) unmounts.</li>
</ul>
<p>So this is how we create an Alert system in React using Contexts and Hooks. Get the full code for this alert-system in my <a href="https://github.com/tripathics/alerts-demo">tripathics/alerts-demo github repository</a>.</p>
